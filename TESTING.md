# Pruebas Unitarias del Proyecto Backend Hoteles

## Descripción
Este documento describe la ejecución de las pruebas unitarias implementadas
para el sistema Backend de Hoteles desarrollado en Python, como parte de la
Tarea 02.04 de la asignatura Ingeniería de Software.

Las pruebas permiten verificar el correcto funcionamiento de los servicios
principales del sistema, garantizando la calidad del software.

## Frameworks utilizados
Para la implementación de las pruebas unitarias se utilizaron los siguientes
frameworks y herramientas:

- Pytest
- Unittest
- Coverage.py

## Ejecución de pruebas unitarias
Para ejecutar las pruebas unitarias del proyecto, se debe utilizar el siguiente
comando desde la raíz del proyecto:

```bash
python -m pytest
